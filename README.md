# papierkram-cli

Command-line client for the [Papierkram](https://www.papierkram.de) API (accounting, invoices, expenses, time tracking), built for humans and AI agents alike. Inspired by `hcloud`, `gh`, `sentry-cli` and `jira-cli`.

> **Status:** design phase. No usable binary yet.
> - Design spec: [`docs/specs/2026-11-03-papierkram-cli-design.md`](docs/specs/2026-11-03-papierkram-cli-design.md)
> - Implementation plan: [`docs/plans/2026-11-03-papierkram-cli.md`](docs/plans/2026-11-03-papierkram-cli.md)
> - API spec snapshot: [`api/`](api/)

The binary is called `papierkram`. Package managers also install a `pk` shortcut. Note: [pkram](https://github.com/mickeyl/pkram) defines a `pk` alias as well; if you use both, the one earlier in your `PATH` wins.
