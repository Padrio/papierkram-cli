# papierkram-cli

Kommandozeilen-Client für die API von [Papierkram](https://www.papierkram.de) (Buchhaltung, Rechnungen, Angebote, Belege, Projekte, Zeiterfassung), gebaut für Menschen und KI-Agents gleichermaßen. Vorbilder: `hcloud`, `gh`, `sentry-cli`, `jira-cli`.

> **Status:** Designphase. Noch kein nutzbares Binary.
> - Design-Spec: [`docs/specs/2026-11-03-papierkram-cli-design.md`](docs/specs/2026-11-03-papierkram-cli-design.md)
> - Implementierungsplan: [`docs/plans/2026-11-03-papierkram-cli.md`](docs/plans/2026-11-03-papierkram-cli.md)
> - API-Spec-Snapshot: [`api/`](api/)

Das Binary heißt `papierkram`. Paketmanager installieren zusätzlich die Kurzform `pk`. Hinweis: [pkram](https://github.com/mickeyl/pkram) legt ebenfalls einen Alias `pk` an; wer beides nutzt, bekommt das Programm, das zuerst im `PATH` steht.
